# Contributing

Contributions are welcome when they improve a **principle, invariant, experiment, adapter, or measurement**.

Please avoid PRs whose only purpose is to add another model/provider without a hypothesis.

A useful contribution should answer at least one of these:

1. What orchestration property are we trying to prove?
2. What failure mode does the change address?
3. What observable metric or invariant changes?
4. Can the experiment be reproduced?
5. Does the result generalize beyond one vendor?

For experiment PRs, include:
- hypothesis
- baseline
- treatment
- exact task corpus
- success criteria
- raw or summarized run evidence
- limitations
- conclusion
